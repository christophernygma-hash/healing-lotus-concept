# Healing Lotus Concept

A conceptual redesign and operating-system demo for Healing Lotus Head Spa Massage in Virginia Beach.

## What is included
- Responsive static website
- Service architecture
- Membership concept
- Guest experience standard
- Associate onboarding
- Service standards
- Opening/closing checklists
- Manager scorecard
- Research notes and publication safeguards

## Run locally
Open `website/index.html` in a browser. The site uses relative links and requires no build system.

## Important
This is an interview demonstration, not the official Healing Lotus website. Public facts, pricing, policies and booking details must be verified before publication.
